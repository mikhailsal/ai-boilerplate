# P01 Build and test the minimal core

Status: DONE

Implementation commit: `5951126` (feat(core): add policy, diagnostics, and
process core).

## Delivered

- Locked core tooling in `tools/quality/pyproject.toml` and `uv.lock`
  (uv 0.12.24, CPython 3.14.8, Ruff, Pyright strict, pytest, coverage.py).
- Typed policy models for `quality.toml`: unknown keys rejected at every
  level, strict scalar types (no string-to-number or number-to-boolean
  coercion), normalized relative paths, narrow globs, dated exceptions, and
  cross-field validation of ownership overlaps, references, and duplicates.
- Generated policy JSON Schema in `docs/reference/policy.schema.json`, with
  `quality policy schema --check` for staleness.
- Structured diagnostics with stable rule IDs, remedies, deterministic
  ordering, text and JSON output, and `quality explain`.
- Subprocess runner: argument arrays only, explicit absolute working
  directory, executable resolution from the child PATH only, allowlisted
  environment, bounded output, timeouts, and process-group termination with
  SIGKILL escalation on timeout or interruption.
- Bounded report readers: size limits, symlink rejection, strict JSON
  (no NaN or Infinity), and defusedxml with DTDs and entities forbidden.
- Core layout and native commands in [tools/quality/README.md](../../../tools/quality/README.md).
