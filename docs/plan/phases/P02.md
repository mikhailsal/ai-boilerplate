# P02 Implement discovery and candidate snapshots

Status: DONE

Implementation commit: `2dad3fa` (feat(discovery): add candidate snapshots,
discovery, and classification).

## Delivered

- `quality.gitio`: repository discovery that honors only `GIT_DIR` and
  `GIT_WORK_TREE` and drops every other inherited Git variable; pinned
  per-call configuration (`core.fsmonitor=false`, no quoting, no color);
  candidates from a copied index (default or alternate) or from a revision,
  identified by tree ID and rechecked with `verify_unchanged`.
- Isolated snapshots from `ls-tree -r -z -l` and `cat-file --batch`: exact
  blob bytes with no filters, executable bits, relative symlinks contained
  with `realpath`, gitlinks as empty directories, LFS pointers as pointers,
  and a check that no project marker sits above the snapshot.
- Changed lines for commit (index against HEAD or the empty tree), amend and
  merge commits, push (zero revision), merge queue, and pull requests with
  base, source head, and tested snapshot, including conflict resolutions.
- `quality.discovery`: file types by name, extension, and shebang; manifest
  parsing without execution; longest-root ownership and regions; categories,
  explicit classification limits, submodule and missing-root checks; helper
  activation.
- `policy.conflict` for classifications that assign `source` or `tests`.
- `quality inventory [--rev REV] [--json]`, honoring the caller's
  `GIT_INDEX_FILE`. Text output escapes control characters and undecodable
  bytes; JSON output is ASCII-only.
- [Decision 0006](../../decisions/0006-discovery-and-classification.md);
  [decision 0004](../../decisions/0004-candidate-snapshots.md) amended for
  `realpath` containment, the object-store side effect of `write-tree`, and
  the isolation check.

## Limitations and follow-ups

- `verify_unchanged` is called by `quality inventory`; the commit gate (P05)
  must call it before reporting success, and P05 rechecks A06 and A07
  through real hooks.
- Discovery checks ownership and categories only; gates per category (size,
  documentation, secrets) arrive in P03, coverage in P04.
- Snapshots are written under the system temporary directory; the isolation
  check fails rather than guessing when a project marker is found above it.
- Inherited configuration of native tools beyond Git (for example
  `NODE_OPTIONS`) is sanitized by the process layer; per-profile proofs of
  R03.8 follow in P05–P08.
