## Limitations and follow-ups

- Timings come from a workstation shared with other work, with load
  averages between 3 and 25, so they vary by tens of percent between runs.
- The remaining check time is the per-component pipeline, which runs one
  component after another. Running components concurrently, keeping the
  Dart helper's compiled test runner between checks, merging the two
  gitleaks scans, and the 19 seconds spent in the core after the last suite
  are the next candidates.
- The hosted jobs install PHP from the ondrej PPA, which is being merged
  into packages.sury.org and answered 503 for two runs of this phase; the
  workflow was left unchanged, because the outage is outside the candidate
  and a new source is the owner's choice.
- The protection stays prepared, not applied
  ([handoff](../handoff.md#hosting)).
- Earlier phases left a `python3.14` link in this machine's `~/.local/bin`;
  it is outside the repository and was left for the user to remove.
