## Scope

Supported: React + Vite + TypeScript single-page applications with static
production output on Linux, as a browser target of the TypeScript profile.
Unsupported and reported: other frameworks, SSR, React Server Components,
meta-frameworks, React Native, other bundlers, Sass, Less, Stylus, Vitest
Browser Mode, and browsers other than Chromium
([decision 0017](../../decisions/0017-browser-frontend-profile.md#scope)).
Unchanged: R01–R10, the thresholds of `quality.toml`, the hooks, the four
Tier 1 profiles, and the provider-neutral CLI.
