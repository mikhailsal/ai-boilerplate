# F01 Extend the schema and register the browser variant

Status: DONE

## Scope

The component model of
[decision 0017](../../decisions/0017-browser-frontend-profile.md#component-model)
in the policy, activation of shipped examples, registration through
`component add --target`, and an explicit failure for every browser
component until its gates exist.

## Changes

| Area | Change |
| --- | --- |
| `policy` | `target`, `framework`, `bundler`, and `[components.browser]` (entries, public values, server modules and packages, viewports); `Role.EXAMPLE`; one validator for the declaration; regenerated `policy.schema.json` |
| `discovery` | `activation`: an example runs in maintainer mode or when changed, never because of another component; `frontend`: React/Vite evidence from `package.json`, `vite.config.*`, and `index.html`, and unsupported frameworks, meta-frameworks, and bundlers |
| `cli` | `component add --target node\|browser`; ambiguity without `--target`; `ui` added for a browser component; nothing in the project is edited |
| `adapters/typescript` | `typescript.browser-incomplete`, an environment finding returned by `prepare`, `provision`, and `probe` for a browser component |
| `ci` | An example's root is a control file like the tooling and helpers |
| Documentation | Decision 0017 registration, the command reference, the profile matrix |

No migration: an existing component has no `target` and runs on Node, and
every existing policy and acceptance test passed unchanged.
