# Agent instructions

This repository is a Git template whose quality gate is the `quality`
command-line tool in [`tools/quality`](tools/quality/README.md). Hooks and CI
only call it; a pass or fail comes from the tool, not from the wrapper.

## Setup

```sh
(cd tools/quality && uv sync --frozen --python 3.14.8)
PYTHONPATH=tools/quality/src tools/quality/.venv/bin/python -m quality tools install
```

Until the `./quality` launcher exists, run every command below as
`PYTHONPATH=tools/quality/src tools/quality/.venv/bin/python -m quality <command>`.

## Checks

- `quality check` checks the staged candidate in an isolated snapshot; stage
  your changes first, because unstaged and untracked files are ignored.
- `quality check --rev HEAD` checks a commit.
- `quality explain <rule-id>` explains a finding and its fix.
- `quality links` probes external links in the documentation. It needs the
  network and is not part of `quality check`.
- `quality policy validate` validates [`quality.toml`](quality.toml).
- Core development commands (format, lint, types, tests) are listed in the
  [core README](tools/quality/README.md#native-development-commands).

## Boundaries

- [`quality.toml`](quality.toml) is the only place for thresholds, components,
  classification, and exceptions. Link to it; do not copy its values.
- Core packages depend only on lower layers
  ([decision 0003](docs/decisions/0003-architecture.md)); the layers are
  declared in `quality.toml` and enforced by `quality check`.
- `docs/reference/policy.schema.json` is generated by
  `quality policy schema --write`; never edit it by hand.
- Write documentation and comments in English. Keep every page linked from
  the [documentation index](docs/README.md).

## Exceptions

Fix the finding first. When an exception is justified, add an
`[[exceptions]]` entry to `quality.toml` with the rule ID, the exact path, the
symbol (for an inline marker, its text from the marker on), a reason, an
owner, and `expires` for a temporary or `review` for a permanent exception.
Expired and unused exceptions fail the check; rules about the policy, Git,
discovery, secrets, and exceptions themselves cannot be excepted. Details are
in [decision 0007](docs/decisions/0007-common-gates.md).
